Install BC2Fab

Follow this guide to configure the BC2Fab table mirroring setup in Business Central and to install the BC2Fab workload in Microsoft Fabric.

Before you begin

Make sure you have completed all prerequisites before installing BC2Fab.

Configuring BC2Fabric Table Setup in Business Central

Use the BC2Fabric Table Config page to choose which Business Central tables will be mirrored to Fabric and to enable logging for incremental processing.

  1. In Business Central, use the search to open BC2Fabric Setup.
  2. In the Administration section, choose Mirroring Tables to open the BC2Fabric Table Config page.
  3. Under Tasks, select Set Default Setup. Around 250 reporting-relevant tables are added automatically.
  4. Ensure that the Mirroring flag is enabled for every table that should be replicated to Fabric.
Optional: Only if you need custom tables or custom queries. If you’re using the default setup, you can skip steps 6–8 below.
  1. Review the list and remove or add tables to match your reporting needs.
  2. When adding new tables or custom endpoints, select the Entity Set Name using the lookup (...) to choose from the available API query endpoints. The selected API must expose columns named systemRowVersion and systemId exactly.
  3. For custom tables or fields, generate API queries with the Query generator to ensure naming conventions align with the mirroring process.

Prefer to see the process in action? Watch the video below for a walkthrough of the table setup steps.

Installing BC2Fab Workload in Fabric

Installing BC2Fab in Fabric happens in two stages: first add the workload to your capacity or tenant, then install it inside the workspace where the mirroring should occur.

Add Workload to Capacity or Tenant

Assign the BC2Fab workload to your Fabric capacity or entire tenant so that your Business Central data can be mirrored and stored in Fabric.

  1. Go to the Fabric workloads hub at app.fabric.microsoft.com.
  2. Search for the BC2Fab workload or use the direct workload link.
  3. Select Manage - By Capacity and choose the capacities where BC2Fab should become available or select "Add to entire tenant" to make it available in the entire tenant.
  4. Click update to complete the assignment.

Install Workload in Workspace

Open the workspace where you want the BC2Fab mirroring to happen.

  1. Click New item, then select BC2Fab under Get item.
  2. When prompted, enter a name for the workload (for example, BC2Fab workload).
  3. In the workload page that opens, provide the following information (both from the prerequisites page):
    • App registration ID
    • Key Vault URI
    • The name of the environment
    • List of companies that should be loaded.
  4. Click Install to start the setup. This will perform the following steps:
    • Validation to ensure a correct setup, access to Key Vault and Business Central
    • Creation of Mirroring database, pipeline and other relevant components
    • Initial full load from Business Central to Fabric
    • Activation of daily refresh schedule
