Install BC2Fabric

Follow this guide to configure the BC2Fabric table mirroring setup in Business Central and to install the BC2Fabric workload in Microsoft Fabric.

Before you begin

Make sure you have completed all prerequisites before installing BC2Fabric.

Configuring BC2Fabric Table Setup in Business Central

Use the BC2Fabric Table Config page to choose which Business Central tables will be mirrored to Fabric and to enable logging for incremental processing.

  1. In Business Central, use the search to open BC2Fabric Setup.
  2. On the General tab, enable Deletion Logging. This ensures deletions on mirrored tables are captured.
  3. In the Administration section, choose Mirroring Tables to open the BC2Fabric Table Config page.
  4. Under Tasks, select Set Default Setup. Around 250 reporting-relevant tables are added automatically.
  5. Ensure that the Deletion Logging and Mirroring flags are enabled for every table that should be replicated to Fabric.
Optional: Only if you need custom tables or custom queries. If you’re using the default setup, you can skip steps 6–8 below.
  1. Review the list and remove or add tables to match your reporting needs.
  2. When adding new tables or custom endpoints, select the Entity Set Name using the lookup (...) to choose from the available API query endpoints. The selected API must expose columns named systemRowVersion and systemId exactly.
  3. For custom tables or fields, generate API queries with the Query generator to ensure naming conventions align with the mirroring process.

Installing BC2Fabric Workload in Fabric

Add the BC2Fabric workload to your Fabric capacity or workspace so that your Business Central data can be mirrored and stored in Fabric.

  1. Go to the Fabric workloads hub at app.fabric.microsoft.com.
  2. Search for the BC2Fabric workload or use the direct workload link.
  3. Select Add, then choose whether to add the workload to the entire capacity or to a specific workspace.
  4. Confirm to complete the installation.
